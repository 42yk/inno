# AGENTS.md

## 작업 시작 전 필수

1. 모든 작업 전에 [`docs/agent-guidelines.md`](docs/agent-guidelines.md)를 읽고 따른다.
2. [`docs/README.md`](docs/README.md)에서 현재 작업에 필요한 기준 문서를 확인한다.
3. 범위 판단이 필요하면 [`subject.md`](subject.md)와 사용자 결정을 확인한다.

## 문서 기준

- `docs/superpowers/`는 설계 과정과 결정 기록이다. 현재 구현의 유일한 기준으로 사용하지 않는다.
- 설계 기록에 있는 요구사항·아키텍처·데이터 흐름·운영 정책은 `docs/superpowers/` 밖의 독립 문서에도 존재해야 한다.
- 독립 기준 문서는 [`docs/README.md`](docs/README.md)에 등록하고, 설계가 바뀌면 같은 작업에서 함께 갱신한다.
- 필요한 독립 문서가 없거나 설계 기록과 충돌하면 구현을 진행하기 전에 문서를 먼저 정렬한다.

## 작업 제한

- 관련 없는 사용자 변경을 수정하거나 되돌리지 않는다.
- 사용자가 명시적으로 요청하지 않으면 커밋, 푸시, PR을 수행하지 않는다.
- 관련 검증 없이 완료라고 보고하지 않는다.
