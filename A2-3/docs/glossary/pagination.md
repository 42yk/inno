# 페이지네이션

- 용어집 색인: [`README.md`](README.md)
- 목록 흐름: [`../data-flow.md`](../data-flow.md#8-list-필터정렬페이지-조회)

페이지네이션(Pagination)은 많은 결과를 한 번에 모두 보여주지 않고 일정한 크기의 페이지로 나누어 조회하는 방식이다.

예를 들어 48건을 페이지당 10건씩 표시하면 다음과 같다.

```text
1페이지: 1~10번째
2페이지: 11~20번째
3페이지: 21~30번째
4페이지: 31~40번째
5페이지: 41~48번째
```

이 프로젝트의 `list` 명령은 `--page`와 `--size`를 사용한다.

```bash
python main.py list --page 2 --size 10
```

SQLite의 LIMIT/OFFSET 방식에서 시작 위치는 다음과 같이 계산한다.

```text
offset = (page - 1) × size
```

따라서 2페이지, 페이지 크기 10이면 `offset = 10`이고 11번째 결과부터 최대 10건을 읽는다.

## 안정된 정렬이 필요한 이유

페이지네이션에는 항상 안정된 정렬이 필요하다. 같은 값이 많은 열로 정렬할 때는 내부 ID를 두 번째 정렬 기준으로 사용해 같은 요청의 항목 순서가 임의로 바뀌지 않게 한다.

필터와 정렬이 바뀌면 결과 집합도 달라지므로 사용자는 첫 페이지부터 다시 조회해야 한다.

## 사용하는 이유

- 콘솔에 수천 건을 한꺼번에 출력하지 않는다.
- DB가 한 번에 읽고 변환하는 데이터 양을 제한한다.
- 사용자가 원하는 구간을 반복해서 탐색할 수 있다.
- 전체 건수와 현재 위치를 함께 표시할 수 있다.
