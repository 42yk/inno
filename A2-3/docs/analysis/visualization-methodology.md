# 시각화와 집계 방법론

- 상태: 현재 구현의 해석 기준
- 구현 근거: `review_analytics/output/charts.py`
- 품질 지표 근거: `review_analytics/rules/metrics.py`

## 1. 별점×감정 누적 막대의 정의

`_rating_sentiment_matrix(data: DashboardData)`는 별점 1~5를 x축으로 두고 각 별점에서 `positive`, `neutral`, `negative`로 분류된 리뷰 **건수**를 쌓아 올린다. 입력은 별점과 감정이 모두 존재하는 `DashboardData.rows`이며, 누락값은 집계에서 제외한다.

이 차트는 별점과 감정의 통계적 상관계수를 계산하지 않는다. 정확한 명칭은 “별점별 감정 건수 교차표의 누적 막대 표현”이며, 같은 별점 안의 감정 구성과 별점별 리뷰 규모를 한 화면에서 탐색하기 위한 기술통계다.

## 2. 누적 막대를 선택한 이유

- 별점 1~5라는 이산 순서형 범주를 그대로 x축에 유지한다.
- 한 막대에서 감정별 건수와 전체 리뷰 수를 동시에 확인할 수 있다.
- 1~2점의 부정, 4~5점의 긍정처럼 기대 방향과 다른 분류를 빠르게 찾을 수 있다.
- 원형 차트나 개별 막대보다 별점 간 모집단 크기 차이를 보존한다.
- 현재 구현이 제공하는 단순 건수만으로 만들 수 있어 별도의 통계 모델 가정을 추가하지 않는다.

`calculate_quality_metrics()`의 별점·감정 일치율은 별점 1~2를 부정, 3을 중립, 4~5를 긍정으로 기대해 일치 비율을 계산한다. 이 지표와 누적 막대는 서로 보완적이다. 일치율은 한 숫자로 전체 경향을 요약하고, 누적 막대는 어느 별점에서 불일치가 발생했는지 보여준다.

## 3. 장점과 한계

| 관점 | 장점 | 한계 |
| --- | --- | --- |
| 규모 | 별점별 전체 리뷰 수와 감정 건수를 보존 | 리뷰 수가 많은 별점이 시각적으로 지배함 |
| 구성 | 한 별점 안의 감정 혼합을 확인 | 중간·상단 조각은 공통 기준선이 없어 정밀 비교가 어려움 |
| 해석 | 운영자가 직관적으로 읽기 쉬움 | 비율 차이의 통계적 유의성을 보여주지 않음 |
| 데이터 요구 | 별점과 감정 enum만 있으면 됨 | 누락 별점·미분석 리뷰가 제외되어 선택 편향이 생길 수 있음 |
| 관계 | 기대와 다른 감정의 위치를 탐색 | 인과관계나 선형 상관을 증명하지 않음 |

차트를 해석할 때 각 별점의 표본 수, 전체 분석 완료율, 평균 신뢰도를 함께 본다. 표본이 적은 막대의 작은 차이를 운영 결론으로 확정하지 않는다.

## 4. 통계적 근거와 확장 분석

현재 집계의 통계적 기반은 두 범주형 변수의 빈도를 세는 교차표다. 보고서에는 관측 건수와 비율을 기술통계로 제시할 수 있지만, “별점이 감정을 유발했다”거나 “강한 상관이 검증되었다”고 표현해서는 안 된다.

추론이 필요하면 목적에 맞춰 다음을 추가한다.

- 별점과 감정의 독립성: 기대빈도를 확인한 뒤 카이제곱 검정
- 관계의 효과 크기: Cramér's V와 신뢰구간
- 별점 순서와 감정 확률의 변화: 순서형 또는 다항 로지스틱 회귀
- 상품·기간의 영향 통제: 상품, 기간, 소스 등을 공변량으로 둔 회귀

카이제곱 검정은 표본이 충분하고 기대빈도가 지나치게 작지 않을 때만 사용한다. p-value만 보고 중요도를 판단하지 않고 효과 크기와 실제 건수를 함께 보고한다. 현재 CLI에는 이러한 추론 통계가 구현되어 있지 않다.

## 5. 대안 비교

| 방식 | 적합한 질문 | 장점 | 단점·주의점 |
| --- | --- | --- | --- |
| 현재 건수 누적 막대 | 어느 별점에 리뷰와 감정이 몇 건 있는가? | 규모와 구성을 함께 보존 | 별점별 구성비 비교가 어려움 |
| 100% 누적 막대 | 별점마다 감정 비율이 어떻게 다른가? | 모집단 크기 차이를 제거해 구성 비교가 쉬움 | 실제 리뷰 수를 숨기므로 건수를 별도 표기해야 함 |
| 히트맵 | 별점×감정 조합의 집중 위치는 어디인가? | 많은 셀을 빠르게 비교 | 색상 척도에 민감하고 작은 표본이 과장될 수 있음 |
| 평균 감정 점수 | 별점별 감정의 평균 방향은 무엇인가? | 한 줄로 추이를 요약 가능 | `negative=-1`, `neutral=0`, `positive=1` 같은 임의 간격 가정이 필요하고 혼합 분포를 숨김 |
| 카이제곱+Cramér's V | 두 범주형 변수가 관련 있는가, 효과는 어느 정도인가? | 유의성과 효과 크기를 정량화 | 인과를 말할 수 없고 충분한 기대빈도가 필요 |
| 순서형·다항 회귀 | 별점 변화와 감정 확률의 관계는 무엇인가? | 다른 변수 통제와 불확실성 추정 가능 | 모델 가정, 표본 크기, 해석 역량이 필요 |

운영 대시보드의 기본은 현재 누적 막대로 유지한다. 구성비 비교가 주목적이면 100% 누적 막대와 별점별 `n`을 함께 제공하고, 의사결정에 통계 검증이 필요할 때만 별도 분석에서 효과 크기나 회귀를 사용한다.
