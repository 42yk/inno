# 스프레드시트 수식 형태 입력 시나리오

- 상태: 현재 과제 범위에서 동작이 정의되지 않은 장애 시나리오
- 관련 기능: CSV/XLSX 내보내기
- 런타임 완화: 없음

## 시나리오

리뷰 본문이나 제품명이 `=`, `+`, `-`, `@`처럼 스프레드시트가 수식으로 해석할 수 있는 문자로 시작한 상태에서 사용자가 CSV 또는 XLSX 파일을 내보내고 스프레드시트 프로그램으로 연다.

## 현재 동작

내보내기 모듈은 저장된 `review_text`와 `product_name` 값을 접두사 추가나 이스케이프 없이 기록한다. 따라서 XLSX 셀이나 CSV를 연 프로그램의 가져오기 방식에 따라 해당 값이 수식으로 해석될 수 있다.

이 동작은 원문 보존과 수식 중립화 가운데 무엇을 우선할지 현재 요구사항과 정책에서 정하지 않았기 때문에 유지한다. 이 문서는 수식 중립화, 입력 거부, 값 변경을 구현 기준으로 승인하지 않는다.

## 운영 지침

- 신뢰할 수 없는 출처의 내보내기 파일은 바로 열지 말고 리뷰 본문과 제품명 열을 먼저 검사한다.
- CSV를 스프레드시트로 가져올 때 해당 열을 텍스트 형식으로 지정한다.
- 외부 링크와 매크로 등 스프레드시트 프로그램의 외부 콘텐츠 실행 기능을 비활성화한다.
- 현재 애플리케이션은 위 입력을 안전하게 중립화한다고 보장하지 않는다.

## 향후 범위 결정에 필요한 사항

이 시나리오를 지원 범위에 포함하려면 수식 형태 값을 보존, 중립화, 거부 중 어떻게 처리할지 먼저 결정해야 한다. 결정 이후 CSV와 XLSX의 동일한 출력 계약, 원문 복원 가능성, 사용자 고지, 회귀 테스트를 함께 정의한다.
