# PikUme 광고 스토리보드

## 브랜드 아이덴티티

| 항목 | 내용 |
| --- | --- |
| 브랜드명 | PikUme |
| 서비스 | 사진과 일기를 기반으로 AI가 추억 이미지를 생성하는 감정 기록 서비스 |
| 타겟 | 일상을 기록하고 추억으로 남기고 싶은 사용자 |
| 톤앤매너 | 따뜻함, 동화책 감성, 힐링 |
| USP | 일기를 AI가 한 장의 추억 이미지로 재해석하여 감정을 시각적으로 기록할 수 있다. |

## 캠페인 목표

> PikUme의 핵심 기능인 '일기를 AI 추억 이미지로 생성하는 경험'을 소개하고, 감정을 기록하는 새로운 방식을 사용자에게 알린다.

## 핵심 메시지

> 기억은 흐려져도, 그날의 감정은 다시 만날 수 있습니다.
