# 데이터 출처와 수집 정책

## 1. 채택 데이터

이 과제는 기상청 기상자료개방포털의 종관기상관측(ASOS) 일자료를 사용한다.

| 항목 | 값 |
| --- | --- |
| 제공기관 | 기상청 국가기후데이터센터 |
| 관측망 | 종관기상관측(ASOS) |
| 지점 | 서울 |
| 지점번호 | `108` |
| 자료 단위 | 일 |
| 분석 기간 | 1994-01-01 ~ 2024-12-31 |
| 예상 달력 일수 | 11,323일 |
| 원본 형식 | 연도별 ZIP 내부의 CP949 CSV |
| 이용조건 | 공공저작물 출처표시 제1유형 |

공식 자료:

- [기상청 기상자료개방포털 ASOS 자료](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36)
- [기상청 ASOS 연도별 파일셋](https://data.kma.go.kr/data/grnd/selectAsosList.do?pgmNo=34)
- [공공데이터포털 ASOS 일자료 조회서비스](https://www.data.go.kr/data/15059093/openapi.do)
- [공공데이터포털 지상기상관측 지점정보 조회서비스](https://www.data.go.kr/data/15139439/openapi.do)
- [기상자료개방포털 저작권 보호 및 정책](https://data.kma.go.kr/cmmn/static/staticPage.do?page=pageCr)

## 2. 선정 이유

기상청 ASOS 자료를 선택한 이유는 다음과 같다.

- 서울을 대표하는 동일 지점번호의 장기 일자료를 제공한다.
- 평균·최저·최고기온을 섭씨 단위로 제공한다.
- 강수량, 습도, 풍속, 기압 등 보조 기상요소도 포함한다.
- 원자료 제공기관, 관측망, 지점번호와 이용조건이 명확하다.
- 연도별 파일을 보존할 수 있어 수집 결과를 재현하고 감사하기 쉽다.

## 3. 검토 후 제외한 후보

### Kaggle 서울 날씨 데이터

[Kaggle의 `Seoul Historical Weather Data (1994 - 2024)`](https://www.kaggle.com/datasets/alfredkondoro/seoul-historical-weather-data-2024)은 게시자 `alfredkondoro`(표시명 Alfredo)가 제공하며 페이지에는 MIT 라이선스가 표시돼 있다. 기간과 변수 구성은 적합하고 내려받기 쉽지만, 데이터 설명의 출처가 구체적인 관측기관 대신 대체 문구로 남아 있고 제목과 본문의 기간 정보도 일관되지 않는다. 원 관측기관과 계보를 확인할 수 없어 주 데이터에서 제외한다. 이 내용은 2026-08-23에 다시 확인했다.

### NOAA GHCN-Daily

NOAA GHCN-Daily는 공식 출처와 품질검사 체계가 명확하다. 다만 이번 과제는 서울 단일 지점 분석이므로 국내 관측 지점과 자료 설명이 명확한 기상청 ASOS를 우선한다. NOAA 자료는 기본 분석에 포함하지 않는다.

두 후보는 기상청 자료 수집이 불가능하거나 중대한 품질 문제가 확인될 때만 대체 후보로 다시 검토한다. 서로 다른 출처의 관측값을 행 단위로 단순 병합하지 않는다.

## 4. 수집 방식

### 편의 수집 방식

`seoul-weather download`와 `python -m seoul_weather download`는 기상청 공개 파일셋 화면과 동일한 요청 흐름으로 연도별 파일 정보를 조회하고 내려받는 선택적 편의 기능이다. 과제 수행에 자동 다운로드가 필수인 것은 아니다. 분석 계약에 맞는 표준 CSV를 직접 준비할 때는 [수동 데이터 입력 지침](../guides/manual-data-input.md)을 따르고 `analyze`만 실행한다.

1. 대상 연도와 서울 지점 `108`로 파일셋을 검색한다.
2. 응답에서 파일셋 번호, 상세 번호, 원본 파일명을 추출한다.
3. 공개 다운로드 요청을 보내 연도별 ZIP을 받는다.
4. 내려받은 응답이 실제 ZIP인지 확인한다.
5. 바깥 ZIP과 안쪽 ZIP을 차례로 푼다.
6. 최종 CP949 CSV를 읽어 원본 컬럼을 확인한다.

초기 수집 경로 검증에서는 1994년과 2024년 파일을 먼저 내려받아 CSV까지 확인했다. 최종 검증에서는 같은 흐름으로 1994~2024년 31개 연도를 모두 실다운로드했고, manifest의 31개 항목과 93개 파일 기록을 크기·SHA-256으로 재확인했다. 다만 화면 내부 요청 주소는 공식 OpenAPI 계약이 아니므로 포털 개편 시 바뀔 수 있다.

### 원자료 수동 확보 방식

자동 수집 경로가 변경되면 다음 순서로 대응한다.

1. 기상자료개방포털 파일셋 화면에서 연도별 자료를 수동 다운로드한다.
2. 공공데이터포털 ASOS 일자료 OpenAPI 활용신청 후 서비스 키로 수집한다.
3. 수집 방법이 달라지면 원자료 파일명, 요청 조건, 접근일을 갱신한다.

OpenAPI 키는 환경변수로만 전달하고 코드, 문서, 로그, Git 관리 파일에 기록하지 않는다.

## 5. 원자료 보관 정책

원자료는 다음과 같이 보관한다.

```text
data/raw/asos/
├── manifest.json
├── 1994/
│   ├── downloaded.zip
│   ├── SURFACE_ASOS_108_DAY_1994_1994_2018.zip
│   └── SURFACE_ASOS_108_DAY_1994_1994_2018.csv
├── ...
└── 2024/
    ├── downloaded.zip
    ├── SURFACE_ASOS_108_DAY_2024_2024_2025.zip
    └── SURFACE_ASOS_108_DAY_2024_2024_2025.csv
```

원본 CSV의 내용과 인코딩은 변경하지 않는다. UTF-8 표준화와 컬럼명 변경은 `data/processed/`의 가공 파일에만 적용한다.

`manifest.json`은 연도별로 다음 값을 기록한다.

- 지점번호
- 대상 연도
- 포털 파일명
- 파일셋 번호와 상세 번호
- 수집일시와 출처 URL
- 파일 크기
- SHA-256 해시
- 압축 해제된 CSV 파일명
- 통합 과정에서 제거한 동일 중복 행 수와 원본 파일·CSV 행 위치

## 6. 핵심 원본 컬럼

| 원본 컬럼 | 분석용 컬럼 | 단위 | 용도 |
| --- | --- | --- | --- |
| `지점` | `station_id` | 없음 | 서울 지점 검증 |
| `일시` | `date` | 날짜 | 시계열 인덱스 |
| `평균기온(°C)` | `avg_temp_c` | °C | 장기 추세와 이상 기온 |
| `최저기온(°C)` | `min_temp_c` | °C | 저온 관측과 일교차 |
| `최고기온(°C)` | `max_temp_c` | °C | 고온 관측과 일교차 |
| `일강수량(mm)` | `precipitation_mm` | mm | 보조 설명 |
| `평균 상대습도(%)` | `avg_humidity_pct` | % | 보조 설명 |

연도별 원본 파일에는 지점명이 별도 컬럼으로 포함되지 않는다. 가공 데이터의 `station_name`은 수집 조건과 지점번호 검증이 모두 `108`을 통과한 뒤 `서울`로 부여하는 파생 메타데이터다.

원본 파일의 실제 헤더가 이 표와 다르면 분석을 진행하지 않고 컬럼 변경 여부를 조사한다.

## 7. 지점 메타데이터 확인

2026-08-21에 기상청 공식 지점정보와 관측소 연혁을 확인했다.

| 항목 | 확인 결과 |
| --- | --- |
| 지점명·번호 | 서울 `108` |
| 관측개시일 | 1907-10-01 |
| 현재 주소 | 서울특별시 종로구 송월길 52 서울기상관측소 |
| 현재 좌표 | 위도 37.57142, 경도 126.9658(WGS84) |
| 해발고도 | 85.67m |
| 위치 이력 | 1932-11-01 현재 송월동 위치로 이전 후 현재까지 운영 |

공식 근거:

- [기상자료개방포털 서울 지점 상세 정보](https://data.kma.go.kr/tmeta/stn/selectStnDetail.do?isSelectStn=Y&pgmNo=82&stdStnNo=108)
- [기상청 수도권기상청 서울 100년 관측소 연혁](https://www.kma.go.kr/metropolitan/html/info/business04.jsp)

알려진 위치 이전은 분석 시작인 1994년보다 앞서므로 분석기간과 겹치지 않는다. 다만 분석기간 중 장비나 주변 관측환경의 세부 변경까지 이 자료만으로 모두 배제할 수는 없으므로 리포트의 한계점에 남긴다.

## 8. 출처표시 문구

2026-08-23에 공공데이터포털의 기상청 ASOS 일자료 서비스 메타데이터에서 이용허락범위가 `공공저작물: 출처표시(제1유형)`임을 확인했다. 기상자료개방포털 저작권 정책은 자유이용 전에 개별 저작물의 공공누리 표시를 확인하고 구체적인 출처를 표시하도록 안내한다. 따라서 재배포 시 아래 출처표시와 함께 해당 자료 화면의 최신 공공누리 표시도 다시 확인한다.

README와 REPORT에는 최소 다음 정보를 포함한다.

```text
데이터: 기상청 국가기후데이터센터 종관기상관측(ASOS) 일자료
지점: 서울(108)
기간: 1994-01-01 ~ 2024-12-31
출처: 기상자료개방포털(data.kma.go.kr)
이용조건: 공공저작물 출처표시 제1유형
```

자료를 재배포할 때는 기상청 출처를 제거하거나, 분석자가 직접 관측한 자료처럼 표현하지 않는다.

## 9. 데이터 출처의 한계

- 단일 관측 지점은 서울 전 지역의 미세기후를 모두 대표하지 않는다.
- 관측 장비, 관측 환경, 지점 위치의 변경이 장기 추세에 영향을 줄 수 있다.
- 일평균 기온 계산 방식과 관측 시각은 기상청 정의를 따른다.
- 관측값의 장기 상승 또는 하락만으로 특정 원인을 확정할 수 없다.
- 공개 파일셋 다운로드 화면의 내부 요청 구조는 변경될 수 있다.
