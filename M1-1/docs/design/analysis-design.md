# 분석 설계

## 1. 분석 주제

1994~2024년 기상청 서울 ASOS 일자료를 사용해 장기 기온 추세, 월별·계절별 패턴, 이상 기온을 탐색한다.

## 2. 분석 원칙

1. 원자료를 수정하지 않는다.
2. 결측과 오류를 숨기지 않고 수와 처리 근거를 기록한다.
3. 이상 기온은 분석 대상이며 자동 삭제 대상이 아니다.
4. 그래프에서 확인한 관찰, 관찰의 의미에 대한 해석, 원인에 대한 가설을 분리한다.
5. 단일 지점 자료로 서울 전체 또는 기후 변화의 원인을 단정하지 않는다.
6. 동일한 입력에서 동일한 계산이 재현되도록 분석 절차를 코드로 고정한다.

## 3. 분석 질문과 근거

### Q1. 연평균 기온은 어떻게 변했는가?

확인할 값:

- 연평균 기온
- 5년 이동평균
- 첫 10년과 최근 10년 평균 차이
- 선형 추세 기울기 `°C/10년`
- 전년 대비 연평균 기온 변화량

해석 시 주의점:

- 추세선은 선택한 기간과 지점에서 관찰된 통계적 경향이다.
- 추세만으로 온실가스, 도시화 등 개별 원인의 기여도를 확정하지 않는다.

### Q2. 월별·계절별 패턴은 어떻게 나타나는가?

확인할 값:

- 연도·월별 평균기온
- 월별 장기 평균과 표준편차
- 초기 10년(1994~2003년)과 최근 10년(2015~2024년)의 월별 평균 차이
- 봄·여름·가을·겨울 평균기온

계절 정의:

- 봄: 3~5월
- 여름: 6~8월
- 가을: 9~11월
- 겨울: 12~2월

겨울의 연도는 12월이 속한 달력연도로 단순 집계한다. 연속된 겨울철 사건을 별도 분석하지 않으므로 계절연도 재지정은 하지 않는다.

### Q3. 이상 고온·저온 시기는 언제였는가?

각 일자의 평균기온을 같은 달의 1994~2024년 전체 분포와 비교한다.

계산값:

```text
월별 기온 편차 = 일평균기온 - 해당 달의 장기 평균기온
표준화 편차 = 월별 기온 편차 / 해당 달의 장기 표준편차
```

장기 표준편차는 선택한 1994~2024년 자료 전체를 비교 모집단으로 보고 모표준편차(`ddof=0`)로 계산한다.

분류 기준:

- 표준화 편차가 `+2.5` 이상이면 이상 고온 후보
- 표준화 편차가 `-2.5` 이하이면 이상 저온 후보

이 기준은 관측 오류 삭제 기준이 아니라 탐색 기준이다. 최종 리포트에서는 편차가 큰 날짜를 수치와 함께 제시하고, 외부 원인을 데이터만으로 단정하지 않는다.

### Q4. 데이터가 허용하는 해석의 범위는 어디까지인가?

다음 내용을 결론과 한계점에 명시한다.

- 단일 지점 관측의 대표성
- 지점 또는 관측 환경 변화 가능성
- 강수량·습도 등 외부 변수의 제한적 활용
- 상관관계와 인과관계의 차이
- 31년이라는 분석 기간에 따른 추세 해석 범위

## 4. 데이터 정제

### 4.1 컬럼 선택

필수 컬럼:

- `station_id`
- `date`
- `avg_temp_c`
- `min_temp_c`
- `max_temp_c`

보조 컬럼:

- `precipitation_mm`
- `avg_humidity_pct`

원본의 나머지 컬럼은 가공 데이터에서 제외할 수 있지만 원본 CSV에는 그대로 보존한다.

### 4.2 자료형 변환

- `station_id`: 정수
- `date`: 날짜
- 기온·강수량·습도: 실수

실제로 비어 있는 숫자 필드는 결측으로 유지한다. 비어 있지 않은 문자열을 숫자로 바꾸지 못하면 원문 값과 CSV 행을 오류에 포함하고 분석을 중단한다. 잘못된 값을 조용히 결측이나 `0`으로 바꾸지 않는다.

### 4.3 날짜 검사

- 날짜 오름차순으로 정렬한다.
- 1994-01-01부터 2024-12-31까지 예상 달력과 비교한다.
- 누락 날짜가 하나라도 있으면 개수와 예시 목록을 포함한 오류로 분석을 중단한다.
- 같은 날짜가 2개 이상이면 원본 파일과 값을 비교한다.
- 분석 기간 밖의 행은 오류로 처리한다.

### 4.4 결측치 처리

날짜 행의 완전성은 4.3의 필수 입력 계약이다. 아래 관측률은 모든 날짜 행이 존재하는 상태에서 변수별 유효 관측값이 있는 비율을 뜻하며, 누락 날짜를 허용하는 기준이 아니다.

- 핵심 기온값은 보간하지 않는다.
- 일별 그래프에서는 결측 구간을 연결해 실제 관측처럼 보이게 하지 않는다.
- 월평균은 해당 월 예상 일수의 80% 이상 관측됐을 때만 계산한다.
- 연평균은 해당 연도 예상 일수의 95% 이상 관측됐을 때만 계산한다.
- 기준 미달 월·연도는 결측으로 표시하고 리포트에 명시한다.

### 4.5 의심 자료 검사

다음 조건을 검사한다.

- `min_temp_c > avg_temp_c`
- `avg_temp_c > max_temp_c`
- 상대습도가 0% 미만 또는 100% 초과
- 강수량이 음수
- 평균·최저·최고기온이 `-50°C` 미만 또는 `50°C` 초과인 행

마지막 기준은 단위 오류나 비정상 입력을 찾기 위한 보수적 품질검사선이며 기상청의 공식 극값 기준이 아니다. 기준을 벗어난 행도 자동 삭제하지 않고 날짜를 품질 요약에 기록한 뒤 원자료와 단위를 확인한다.

## 5. 파생 변수

| 변수 | 계산 | 목적 |
| --- | --- | --- |
| `year` | 날짜의 연도 | 연도별 집계 |
| `month` | 날짜의 월 | 월별 패턴 |
| `season` | 월을 4계절로 변환 | 계절별 집계 |
| `daily_range_c` | 최고기온 - 최저기온 | 일교차 확인 |
| `rolling_30d_avg_c` | 일평균기온 30일 이동평균 | 단기 노이즈 완화 |
| `annual_avg_temp_c` | 연도별 일평균기온 평균 | 장기 추세 |
| `annual_change_c` | 전년 연평균과의 차이 | 연도 간 변화 |
| `rolling_5y_avg_c` | 연평균의 5년 이동평균 | 장기 흐름 완화 |
| `monthly_climatology_c` | 달별 31년 평균 | 계절 기준선 |
| `monthly_anomaly_c` | 일평균 - 해당 달 장기 평균 | 같은 계절 내 편차 |
| `monthly_anomaly_z` | 편차 / 해당 달 표준편차 | 이상 기온 후보 |

이동평균은 과거 자료만 사용하는 후행 방식으로 계산한다. 30일 이동평균은 관측값 24일 이상, 5년 이동평균은 5개 연도가 모두 유효할 때만 표시한다.

## 6. 분석 기법

### 6.1 연도별 집계와 이동평균

일별 변동을 연평균으로 집계하고 5년 이동평균을 함께 표시한다. 원시 연평균과 이동평균을 모두 보여줘 평활화가 실제 변동을 숨기지 않도록 한다.

### 6.2 선형 추세

연도를 설명변수, 연평균 기온을 반응변수로 단순 선형회귀한다. 기울기는 `°C/10년`으로 변환한다. 결정계수와 유효 연도 수도 함께 기록한다.

선형 추세는 비선형 변화나 외부 원인을 설명하지 못하므로 결론에서 한계를 명시한다.

### 6.3 월별·계절별 집계

연도×월 평균을 계산해 계절성과 장기 변화를 함께 본다. 초기 10년과 최근 10년의 월별 평균 차이를 계산해 변화가 특정 달에 집중되는지 확인한다.

### 6.4 표준화 편차

각 날짜를 같은 달의 장기 분포와 비교한다. 달마다 평균과 변동폭이 다른 점을 보정하기 위해 표준화 편차를 사용한다.

## 8. 인사이트 형식

각 인사이트는 다음 형식을 사용한다.

```text
관찰(Fact): 그래프와 통계에서 확인한 수치, 날짜 또는 구간
해석(Interpretation): 관찰이 분석 질문에 대해 의미하는 바
가설(Hypothesis): 관찰의 가능한 원인에 대한 검증 전 설명이며 필요한 경우에만 작성
한계(Limit): 현재 데이터만으로 확정할 수 없는 부분
행동(Action): 추가 확인 또는 활용 제안
```

관찰에 없는 원인, 사건, 정책은 해석에 섞지 않고 가설로 분리한다. 가설을 뒷받침하려면 별도 출처를 제시한다.

## 10. 분석 한계

- 단일 관측소 결과를 서울 전 지역의 동일한 변화로 일반화할 수 없다.
- 장기 추세에 영향을 줄 수 있는 도시화, 관측환경, 대기순환 등 외부 변수를 직접 모델링하지 않는다.
- 같은 달을 기준으로 한 표준화 편차는 월 안의 자연스러운 초·중·말 기온 변화를 완전히 제거하지 못한다.
- 선형 추세는 분석 기간의 평균적인 방향을 요약할 뿐 미래를 예측하지 않는다.
- 강수량과 습도는 보조 변수이며 인과 분석에 사용하지 않는다.
