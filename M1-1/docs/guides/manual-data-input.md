# 수동 데이터 입력 지침

## 1. 목적

이 문서는 자동 수집 기능을 사용하지 않고 서울 기온 데이터를 직접 제공해 분석하는 입력 계약을 정의한다. 직접 제공한 데이터도 자동 수집 결과와 동일한 검증을 통과해야 하며, 출처·기간·수집 방법을 별도로 기록해야 한다.

## 2. 파일 위치와 형식

분석할 파일을 다음 경로에 배치한다.

```text
data/processed/seoul_weather_daily.csv
```

- 파일 형식: CSV
- 문자 인코딩: UTF-8
- 헤더: 첫 번째 행에 정확히 한 번 작성
- 구분자: 쉼표(`,`)
- 날짜 형식: `YYYY-MM-DD`
- 숫자 형식: 단위, 천 단위 구분자와 문자 없이 숫자만 작성
- 결측값: 빈 필드로 유지하며 `0`, `-`, `N/A` 같은 대체 문자열을 넣지 않음

## 3. 필수 컬럼

컬럼은 다음 8개를 모두 포함해야 한다. 분석 코드는 아래 이름을 그대로 사용한다.

| 컬럼 | 자료형 | 단위 | 입력 규칙 |
| --- | --- | --- | --- |
| `station_id` | 정수 | 없음 | 모든 행이 서울 지점 `108`이어야 함 |
| `station_name` | 문자열 | 없음 | 모든 행에 `서울` 입력 |
| `date` | 날짜 | 일 | `1994-01-01`부터 `2024-12-31`까지 하루 한 행 |
| `avg_temp_c` | 실수 | °C | 일평균기온, 결측 시 빈 필드 |
| `min_temp_c` | 실수 | °C | 일최저기온, 결측 시 빈 필드 |
| `max_temp_c` | 실수 | °C | 일최고기온, 결측 시 빈 필드 |
| `precipitation_mm` | 실수 | mm | 일강수량, 무강수와 미관측을 구분할 수 없으면 빈 필드 유지 |
| `avg_humidity_pct` | 실수 | % | 평균 상대습도, 결측 시 빈 필드 |

컬럼 순서는 위 표와 같게 작성하는 것을 권장한다. 추가 컬럼은 분석에 사용되지 않으며 가공 파일에는 넣지 않는다.

## 4. 날짜와 행 조건

- 분석 기간은 `1994-01-01`부터 `2024-12-31`까지다.
- 윤년을 포함해 총 11,323개 날짜가 각각 정확히 한 번 존재해야 한다.
- 날짜 중복, 기간 밖 날짜, 누락 날짜가 있으면 분석은 실패한다.
- 행은 날짜 오름차순으로 정렬한다.
- 모든 행의 지점번호는 `108`이어야 한다.
- 기온값이 모두 있는 행은 `min_temp_c <= avg_temp_c <= max_temp_c` 관계를 만족해야 한다.
- 상대습도는 0~100 범위, 강수량은 0 이상이어야 한다. 평균·최저·최고기온이 `-50°C` 미만 또는 `50°C` 초과이면 보수적 품질검사 후보로 기록한다. 의심 값은 임의로 삭제하거나 수정하지 말고 출처와 원자료를 먼저 확인한다.

## 5. 입력 예시

아래 예시는 형식만 설명하며 실제 분석값을 대신하지 않는다.

```csv
station_id,station_name,date,avg_temp_c,min_temp_c,max_temp_c,precipitation_mm,avg_humidity_pct
108,서울,1994-01-01,-1.8,-5.5,2.6,,62.3
108,서울,1994-01-02,-0.7,-4.1,3.2,0.0,58.0
```

첫 번째 행의 빈 강수량은 결측이고, 두 번째 행의 `0.0`은 무강수임이 확인된 관측값이라는 전제에서만 사용한다.

## 6. 출처 기록

직접 제공한 데이터에는 다음 정보를 README 또는 별도 출처 문서에 남긴다.

- 제공기관과 데이터셋 이름
- 원본 페이지 URL
- 관측 지점과 분석 기간
- 내려받거나 전달받은 날짜
- 원본 파일명과 파일 형식
- 이용조건 또는 라이선스
- 원본에서 표준 8개 컬럼으로 변환한 방법
- 결측, 중복, 제외 또는 수정한 행의 수와 처리 근거

기상청 이외의 자료로 바꾸거나 여러 출처를 섞는 것은 분석 조건 변경이므로 먼저 요구사항과 분석 설계를 갱신해야 한다.

## 7. 실행 순서

표준 CSV를 배치한 뒤 다음 명령을 실행한다.

```bash
seoul-weather analyze
# 또는
python -m seoul_weather analyze
python -m pytest -q
```

`analyze` 명령이 필수 컬럼, 날짜 범위, 날짜 중복·누락과 지점번호를 검사한다. 기본 경로가 아닌 파일은 `seoul-weather analyze --input PATH`로 지정한다. 검증에 실패하면 오류 메시지에 따라 원본과 변환 과정을 수정한 뒤 다시 실행한다.
